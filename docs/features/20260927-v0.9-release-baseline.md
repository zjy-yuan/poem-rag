# v0.9.0 发布基线收口

> 状态：候选发布基线，等待提交与打 tag
> 创建日期：2026-09-27
> 最近更新：2026-09-27
> 关联任务：冻结当前性能与并发诊断阶段的可回归快照

## 1. 背景与问题

当前分支已经完成检索批量化、Provider 并发边界诊断和默认关闭的 Embedding
精确缓存，但项目元数据仍停留在 `v0.7.0`。这会导致 OpenAPI、前端包版本、
项目说明和 Git tag 无法互相解释，也不利于后续异步任务、部署和面试演示
使用同一组版本信息。

本阶段不新增业务能力，只把已经通过门禁的实现整理为可识别的候选发布基线。

## 2. 目标

- 后端 OpenAPI 版本与前端包版本统一为 `0.9.0`。
- 后端使用单一版本常量，避免应用工厂和包元数据再次漂移。
- 在功能索引和开发日志中记录本次版本的边界、验证和待完成动作。
- 明确评估报告和冻结数据的保留规则，不删除、不静默覆盖已有证据。

## 3. 非目标

- 不修改在线检索策略、SSE、数据库迁移、前端交互或依赖版本。
- 不启用 Embedding 在线缓存。
- 不实现异步任务 Worker、Docker、生产限流或云部署。
- 不在没有用户确认的情况下提交、推送或创建 Git tag。

## 4. 发布身份

| 项目 | 候选值 | 事实来源 |
| --- | --- | --- |
| Python 包版本 | `0.9.0` | `apps/api/app/__init__.py` |
| FastAPI/OpenAPI 版本 | `0.9.0` | `create_app()` 读取 Python 包版本 |
| 前端包版本 | `0.9.0` | `apps/web/package.json` |
| 文档快照 | `v0.9.0-performance-concurrency` | `docs/PROJECT_GUIDE.md` |
| 候选 Git tag | `v0.9.0-performance-concurrency` | 提交审阅后手动创建 |

版本号只表示当前可回归快照，不等价于生产就绪声明。当前仍缺少任务 Worker、
生产限流、监控、容器化和部署验证。

## 5. 评估报告保留规则

1. 冻结数据集、迁移、测试和结论性功能文档进入版本管理。
2. 重复性能、隔离诊断、探针和中间调参报告默认作为本地可复现产物，
   不自动纳入发布基线。
3. 文档引用的最终报告在打 tag 前逐项确认：要么明确纳入版本管理，
   要么把正文改为只保留指标和复现命令，不保留失效链接。
4. 任何报告都不通过删除来“清理工作区”；未决定前保留本地文件并记录状态。

本版纳入版本管理的里程碑证据：

- `data/eval/reports/retrieval_holdout_1000_v3_{batch_limit_c1_restored,candidate_pool_c1,performance_c1,performance_c4}.json`
- `data/eval/reports/graph_isolation_*_{c1,c4}.json`
- `data/eval/reports/provider_concurrency_*_{c1,c4}.json`
- `data/eval/reports/graph_embedding_v3_real_retrieval_fake_provider_{c1,c4}.json`
- `data/eval/reports/graph_embedding_v3_stability_rerun_{c1,c4}.json`
- `data/eval/reports/graph_embedding_cache_c1{,_warm}.json`

以下重复诊断只保留本地，并通过 `.gitignore` 明确排除：

- `data/eval/reports/graph_embedding_smoke_*.json`
- `data/eval/reports/graph_embedding_v3_slowtail*.json`
- `data/eval/reports/graph_embedding_v3_variant*.json`
- `data/eval/reports/retrieval_holdout_1000_v3_variant*.json`
- 既有 `_probe_*`、`profile_*` 和其他中间调参报告

最终报告经检查不含密钥、Token、Cookie、请求头或用户凭证；其中的诗词正文来自固定
公开数据集，报告只补充可复现的运行指标和样本标识。

## 6. 验收标准

| 场景 | 操作 | 预期结果 |
| --- | --- | --- |
| 查看 OpenAPI | 请求 `/openapi.json` | `info.version` 为 `0.9.0` |
| 查看前端包 | 读取 `apps/web/package.json` | `version` 为 `0.9.0` |
| 版本漂移测试 | 运行后端测试 | 应用版本必须等于包版本常量 |
| 完整门禁 | 运行 `.\scripts\verify.ps1` | Ruff、pytest、typecheck、Vitest 和构建通过 |
| 提交前审阅 | 运行 `git diff --check` 和 `git status` | 无空白错误，报告保留状态明确 |
