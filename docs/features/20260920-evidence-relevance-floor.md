# 证据相关性门槛与拒答判定

> 状态：已实现  
> 创建日期：2026-09-20  
> 最近更新：2026-09-20  
> 关联任务：Dense/Hybrid 无答案误召回修复、LangGraph 条件路由

## 1. 背景与问题

真实索引完成后，四条检索路径在同一 27 条金标准集上做了同集对比，暴露出一个不能靠
“多接一个模型”解决的缺陷：

1. `dense-baseline-v1` 的无答案准确率是 `0.000000`，4 条跨域问题全部返回了 Top-5
   证据。
2. `hybrid-rrf-v1` 同样是无答案准确率 `0.000000`。
3. `expanded-lexical-v1` 之所以没有这个问题，是因为词法检索要求查询与文本存在字符串
   匹配，跨域问题天然没有命中，而不是因为它“更聪明”。

如果直接把 Dense 或 Hybrid 接到在线问答，用户问“唐朝的赋税制度”会得到一段看似有出处
的诗词赏析。检索层不拒绝弱相关结果，生成层就没有机会拒答。

## 2. 目标

- 让检索层能表达“这些候选都不够相关”，而不是永远返回 Top-K。
- 把拒答判定变成 LangGraph 里可观察、可测试的显式分支。
- 用同一评估集证明门槛不会牺牲可回答样本的召回。

## 3. 非目标

- 不实现 Rerank 模型或 Cross-Encoder。
- 不实现 LLM 相关性判定节点。
- 不切换在线问答的检索策略。
- 不引入按查询自适应的动态阈值。

## 4. 用户场景与验收标准

| 场景 | 操作 | 预期结果 |
| --- | --- | --- |
| 跨域提问 | 用 Dense/Hybrid 检索“量子纠缠的物理实验” | 候选全部低于门槛，检索结果为空 |
| 领域内提问 | 用 Dense/Hybrid 检索“表达思乡情绪的诗句” | 命中并保持 Recall@5 不下降 |
| 无证据问答 | 在线问答检索为空 | 走 `refuse` 分支，返回稳定拒答，不调用生成模型 |
| 有证据问答 | 在线问答检索非空 | 走 `generate` 分支，回答必须带 `[n]` 引用 |
| 关闭门槛 | `min_score=0` | 行为与改动前完全一致 |

## 5. 方案概览

候选方案与取舍：

| 方案 | 做法 | 结论 |
| --- | --- | --- |
| A. 对融合分数设阈值 | 在 `hybrid-rrf-v1` 输出上过滤 | 否决。RRF 归一化后只保留排名信息，自然语言问题和跨域无答案问题的融合分数同为 `0.5`，无法区分 |
| B. LLM 相关性判定 | 检索后让模型判断证据是否相关 | 暂缓。增加一次模型调用和延迟，且在无标注数据前无法证明优于阈值 |
| C. 语义分支余弦门槛 | 在 `DenseRetrievalService` 过滤低相似度候选 | 采用。门槛靠近产生分数的分支，可单独评估，Hybrid 通过构造注入自动继承 |

选择 C 的直接原因：只有 Dense 分支保留绝对相似度，融合层只剩排名。任何作用在融合结果
上的阈值都会把“被召回”误当成“相关”。

## 6. 接口与契约

1. HTTP 接口没有变化，公开 `GET /api/v1/search/evidence` 仍固定 `lexical-baseline-v1`。
2. 离线评估脚本新增 `--min-score`，取值 `[0, 1]`，默认 `0`，只对 `dense` 和 `hybrid`
   生效。
3. SSE 事件顺序没有变化；拒答仍然是 `meta -> retrieval -> delta -> done`。
4. 没有新增错误码。门槛只影响检索结果是否为空，不产生新的失败类型。

## 7. 数据设计

不涉及迁移。门槛是检索期参数，不写入 `poem_chunks`、`poem_index_runs` 或引用快照。

## 8. 后端设计

1. `DenseRetrievalService(min_score=...)` 在回查 MySQL 之后丢弃低于门槛的候选，
   `candidate_count` 反映过滤后的数量。
2. `HybridRetrievalService` 不需要新参数：门槛由注入的 Dense 分支承担，词法分支不受
   影响。
3. `RagChatGraph` 增加 `assess` 节点，并用条件边路由到 `generate` 或 `refuse`。
   `refuse` 只写稳定拒答文本和 `finish_reason=no_evidence`，两个分支都汇入 `validate`，
   保持 SSE 事件结构一致。
4. 证据是否充分由节点显式决定，而不是藏在生成函数的早返回里，后续要加“低召回重写
   重试”或“Rerank”时只需扩展 `assess` 的出边。

## 9. 前端设计

不涉及。拒答仍然表现为一段普通 `delta` 文本，前端不需要新增分支。

## 10. RAG 与评估

同集结果（Top-5，27 条样本，2026-09-20）：

| 策略 | 通过 | Recall@5 | 无答案准确率 | 平均延迟 |
| --- | --- | --- | --- | --- |
| `dense-baseline-v1` | 22/27 | 0.956522 | 0.000000 | 233.622 ms |
| `dense-baseline-v1` + `min_score=0.22` | 26/27 | 0.956522 | 1.000000 | 214.939 ms |
| `dense-baseline-v1` + `min_score=0.25` | 26/27 | 0.956522 | 1.000000 | 177.832 ms |
| `dense-baseline-v1` + `min_score=0.30` | 25/27 | 0.913043 | 1.000000 | 191.052 ms |
| `hybrid-rrf-v1` | 23/27 | 1.000000 | 0.000000 | 184.868 ms |
| `hybrid-rrf-v1` + `min_score=0.22` | 27/27 | 1.000000 | 1.000000 | 196.101 ms |
| `hybrid-rrf-v1` + `min_score=0.25` | 27/27 | 1.000000 | 1.000000 | 179.913 ms |

报告文件：`data/eval/reports/retrieval_dense_v1_min022_20260920.json` 和
`data/eval/reports/retrieval_hybrid_v1_min022_20260920.json`。

可用区间与默认值：

1. 4 条跨域无答案样本的最高相似度为 `0.194735`。
2. 可回答样本里最弱的是 `dynasty-song-01`，最高相似度 `0.264723`。
3. `0.22` 和 `0.25` 都落在区间内且结果一致；`0.30` 会让 `dynasty-song-01` 完全无
   结果。项目采用 `0.22` 作为记录在案的推荐值，因为它离无答案上界更近、离召回悬崖
   更远。
4. 该区间只对当前语料（6 首、21 个 chunks）和 `text-embedding-v4` 有效，语料或模型
   变化后必须重新评估。

### 10.1 v2 数据集上的重新标定（2026-09-20）

加入 4 条“领域内无答案”样本后，结论发生变化：

| 策略 | 通过 | Recall@5 | 拒答 P | 拒答 R | 拒答 F1 |
| --- | ---: | ---: | ---: | ---: | ---: |
| `dense-baseline-v1` | 22/31 | 0.956522 | 0.000000 | 0.000000 | 0.000000 |
| `dense-baseline-v1` + `0.22` | 26/31 | 0.956522 | 1.000000 | 0.500000 | 0.666667 |
| `dense-baseline-v1` + `0.50` | 26/31 | 0.804348 | 0.666667 | 1.000000 | 0.800000 |
| `hybrid-rrf-v1` + `0.22` | 27/31 | 1.000000 | 1.000000 | 0.500000 | 0.666667 |
| `hybrid-rrf-v1` + `0.50` | 31/31 | 1.000000 | 1.000000 | 1.000000 | 1.000000 |

关键结论：

1. 跨域负样本最高相似度 `0.1947`，领域内负样本最低相似度 `0.3652`，最弱可回答样本
   `0.2647`。领域内负样本与可回答样本**互相交错**，Dense 单路不存在可分离阈值。
2. `0.22` 仍然成立，但它的作用范围被缩小为“防止跨域漂移”，不能承担可答性判定。
3. Hybrid 的 `0.50` 看似最优，但召回不掉是因为词法分支独立召回了 4 条低相似度
   可回答样本，且与最差负样本只差 `0.0113`，因此不写入在线配置。
4. 详细数据、报告文件和后续方向见
   `docs/features/20260920-answerability-evaluation-v2.md`。

## 12. 风险与回滚

1. 门槛是语料相关的经验值，不是通用常数；换语料、换 Embedding 模型或换距离度量后必须
   重新标定。
2. v2 已补 4 条“领域内但语料无答案”样本，并实测证明门槛无法处理它们；门槛只能
   防跨域漂移，可答性判定必须交给后续的 `assess` 节点。
3. 固定阈值对短查询（例如单字朝代名）最脆弱，`dynasty-song-01` 距离阈值上界很近。
4. 在线策略仍是 `expanded-lexical-v1`，它在 v2 上有 2 条“话题命中、答案缺失”的
   漏拒样本，说明该缺口会直接影响用户。
5. 回滚方式是把 `min_score` 设回 `0`，无需迁移或数据修复。
