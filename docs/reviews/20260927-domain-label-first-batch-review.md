本文档用于记录首批领域标签的语义、证据文本和行号的人工复查结果。当前 15 条关联
已完成审核与人工复查，但样本量仍不足以作为正式金标准，因此不能仅凭本文档评估
标签系统的整体质量。

行号口径：

1. 使用从 `1` 开始的行号。
2. 行号基于当前 `PoemVersion.snapshot.content` 的换行结构。
3. 空行也计入行号；`line_start` 和 `line_end` 均为包含关系。
4. 证据文本必须能够直接支持对应标签；证据与标签有关联但不够直接时，应在复查结论
   中标记“需修改”。

复查时请在每条记录的“人工复查”列选择：

- `通过`：标签、证据和行号均成立。
- `需修改`：标签不准确、证据不直接或行号不正确。
